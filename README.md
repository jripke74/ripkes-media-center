# Ripke’s Media Center

A learning project: building a full-stack media center application (inspired by Infuse, Jellyfin, and Plex).

## Current Status
Frontend only – basic media grid with light/dark theme.

## Getting Started (local)
1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. No server required yet.

## Tech Stack (planned)
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: PostgreSQL
- Hosting: Heroku
- Architecture: MVC + modular

See `DEVELOPMENT.md` for the step-by-step learning notes.
